# Carriage inward treatment + causal drivers (design)
- Inward freight on purchases = inventoriable acquisition cost (Ind AS 2). Allocate to the GRN/receipt lines the freight voucher references (direct); unreferenced freight → pro rata to receipt value within the same supplier/date window.
- Controls: one freight voucher ↔ one allocation set (unique voucher_id); Σ allocated = voucher amount; once allocated, excluded from every overhead pool (anti-join on voucher_id); outbound (Packing & Forwarding to customers, freight-out) and non-inventoriable (demurrage, penalties) are classified separately and never capitalised.
- Drivers (POLICY 2026-10-16): repair the existing system, no time-based spreading, no time studies/time logs. Packing labour keeps the existing EXPECTED_PACKAGE_UNITS driver (accepted). Manufacturing labour keeps ROUTE_ATTENDANCE_WORKLOAD. Salary comes only from the HR roster (flat until a validated change), never from Tally; Tally salary heads stay EXCLUDED.
