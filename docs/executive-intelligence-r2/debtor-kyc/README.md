## Owner-approved revised KYC lifecycle (28 November 2026)
Supersedes the previous all-fields-required and explicit NA/NIL declaration design.
- DRAFT, ACTIVE, INACTIVE; Save incomplete records. Activate only when classification is complete and valid: identity, region, godown, district, area and debtor type. All five classification dimensions are mandatory. Discount and scheme are optional for activation, whether inherited, overridden or unresolved. Optional address/contact/business/GSTIN/notes must never block activation.
- SQL NULL is the canonical absence of optional information; no mandatory NA/NIL markers or field-disposition JSON. Area NULL is permitted for drafts only. Every activated debtor requires an actual area master reference; do not invent geographic assignments or silently substitute text sentinels. Where no subdivision exists, an explicitly governed district-wide area master may be created if approved. Discount 0 and No Scheme are explicit commercial values; NULL override means inherit, unresolved effective commercial defaults are not equivalent to zero.
- Active classification and supplementary profile completeness are distinct. Missing optional contact/address fields may be shown as informational completeness, but never trigger the no-active-KYC management alert when mandatory classification is valid. Alerts include current outstanding debtors with no valid active KYC, including unmatched, draft, inactive or invalid classification. No balance is excluded.
- Inactivate only ACTIVE, reason required; reactivate only after current server validation. Save and transitions require authorized editors, revision checking, locking and audit. Active edits must preserve mandatory classification or require explicit inactivation first; optional profile edits do not invalidate activation. Changes to mandatory geographic/type masters may invalidate effective classification; surface in alerts. Missing, expired or unconfigured commercial terms alone must not invalidate KYC or trigger the no-active-KYC alert. KYC status is not ledger trading status.
